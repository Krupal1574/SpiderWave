## 🎵 What is SpiderWave?

SpiderWave is a modern desktop music player designed around **your collection**, not a subscription.

Whether you're listening to MP3s, FLACs, WAVs, or years of carefully curated playlists, SpiderWave keeps everything fast, organized, and completely under your control.

No ads.
No accounts.
No cloud lock-in.

Just music.

---

## ✨ Features

### 🎧 Playback

* Native audio playback
* Queue management
* Shuffle & Repeat
* Real-time progress tracking
* Volume controls
* Smooth playback experience

### 📚 Library

* Lightning-fast library scanning
* Automatic metadata extraction
* Albums & Artists organization
* Playback history
* Powerful search
* Offline-first experience

### ⚡ Performance

* Native desktop performance
* SQLite-powered library
* Handles large music collections
* Optimized rendering
* Fast startup times

## 🚀 For Developers

```bash
git clone https://github.com/Krupal1574/SpiderWave.git

cd SpiderWave/spiderwave

npm install

npm run tauri dev
```

Production Build:

```bash
npm run tauri build
```
